# React + Apollo Client Practice App

This is a small practice project that uses **React** and **Apollo Client** to interact with a **GraphQL server**. It includes:

- Fetching all users
- Fetching a specific user by ID
- Creating new users with a simple form

## Tech Stack

- React
- Apollo Client
- GraphQL
- JavaScript

## How to Run

1. Start your GraphQL server (make sure it's running on `http://localhost:4000`)
2. Run the React app:

```bash
npm install
npm run dev
```
3. Open the browser on your Vite port
